# 🌟 As Aventuras da Lia — Jogos da Giovana (5 anos)

Suíte de jogos educativos interativos desenvolvida com muito carinho para a Gigi!

## 🎮 Jogos Inclusos:
1. ⛵ **A Travessia da Lia**: Pilote o barquinho pelas praias de Búzios, desvie dos obstáculos e colete os peixinhos e conchas!
2. 🧁 **Ateliê de Delícias da Lia (v0.3)**: 
   - **Receita 1**: Milk-shakes refrescantes (bata as frutas, misture o sorvete e adicione a calda!).
   - **Receita 2**: Cupcakes de Aniversário (escolha a forminha, bata a massa, asse no forninho até crescer, decore e apague a velinha!).
3. 🐜 **Trilha das Formiguinhas**: Guie as formiguinhas coloridas para pintar lindas telas de Búzios pixel por pixel!

## 📱 Como Jogar:
